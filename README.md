# lidar_robot_sim

Небольшая сборка симуляции MuJoCo для 4‑колёсного робота на колёсах меканум с управлением через отдельное окно‑джойстик (Tk) и простым лидаром. Сборка Python‑проекта — через uv.

Что входит:
- MJCF‑модель робота и окружения: `mecanum_lidar/models/mecanum_lidar.xml`.
- Веб‑джойстик: один пад для хода (X страф, Y вперёд), отдельный слайдер для вращения (yaw) и ползунок масштаба скорости. Есть кнопка Stop.
- «Лидар»: программный 2D скан в плоскости XY по цилиндрическим препятствиям (значения выводятся в оверлей вьюера).
- Контактная динамика с имитацией роликов 45° на каждом колесе (упрощённая модель), стены по периметру арены.

Требования:
- Python 3.10+
- Зависимости ставятся через uv: `mujoco`, `numpy`, `fastapi`, `uvicorn` (автоматически по pyproject).

Установка через uv:
1) Создать и инициализировать окружение
   - `uv venv`
   - `uv sync`

2) Запуск симуляции
   - `uv run mecanum-lidar`
   - macOS: обёртка автоматически перезапустит под `mjpython`. Если нужно вручную: `uv run mjpython -m mecanum_lidar.sim`

Управление:
- По умолчанию — веб‑джойстик: откройте в браузере `http://127.0.0.1:8765` и используйте пад (X/Y), слайдер вращения и ползунок скорости (Stop — остановка).
- Опционально Tk‑джойстик (если доступен tkinter): отдельное окно «Mecanum Joystick».

Примечания:
- Модель колёс упрощена (визуально цилиндры), физически «механум‑эффект» не моделируется роликами. Боковое перемещение реализовано на уровне кинематики (по колёсам задаются целевые скорости и подмешивается крутящий момент‑регулятор). В реальной физике MuJoCo для корректного страфа нужны ролики под 45° или анизотропия трения.
- Лидар реализован софтверно: скан лучей в плоскости XY пересекается с цилиндрическими препятствиями сцены. Для простоты препятствия в мире — цилиндры; при добавлении других форм понадобится доработка пересечений.

Структура:
- `pyproject.toml` — метаданные проекта и зависимости (uv)
- `mecanum_lidar/sim.py` — входная точка; запускает FastAPI‑джойстик и симуляцию
- `mecanum_lidar/control_web.py` — сервер FastAPI + WebSocket и джойстик‑страница
- `mecanum_lidar/kinematics.py` — кинематика колёс меканум
- `mecanum_lidar/lidar.py` — простой 2D лидар по цилиндрам
- `mecanum_lidar/models/mecanum_lidar.xml` — MJCF модель
